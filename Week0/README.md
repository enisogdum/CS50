# Problem Set 0: Scratch

## Overview
Implement an interactive project of your choice using **Scratch**, a visual programming language developed by the MIT Media Lab.

## Objectives
- Learn foundational programming concepts: loops, conditions, variables, and functions (custom blocks).
- Create a visual story, game, animation, or interactive experience.

## Specification
Your Scratch project must satisfy the following requirements:
1. **Sprites**: Must contain at least two sprites, at least one of which must not be the default cat.
2. **Scripts**: Must contain at least three scripts total.
3. **Conditionals**: Must use at least one conditional (`if`, `if-else`).
4. **Loops**: Must use at least one loop (`forever`, `repeat`, `repeat until`).
5. **Variables**: Must use at least one variable.
6. **Sounds/Events**: Must use at least one sound, broadcast/receive event, or custom block (`make a block`).

## How to Run / Preview
1. Open [Scratch](https://scratch.mit.edu/).
2. Click **File > Load from your computer** and select `ProblemSet0.sb3`.
3. Click the green flag to run the project.
