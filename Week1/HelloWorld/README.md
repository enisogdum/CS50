# Hello, World!

## Overview
Write a C program that prompts the user for their name and prints a personalized greeting.

## Specification
1. Store your program in a file named `hello.c` (or `helloworld.c`).
2. Prompt the user for their name using `get_string` (from `cs50.h`) or standard input.
3. Print `hello, [name]`, where `[name]` is the name provided by the user, followed by a newline.

## Usage Example
```bash
$ make helloworld
$ ./helloworld
What's your name? Mario
hello, Mario
```

## Testing
Run `check50` to test your code:
```bash
check50 cs50/problems/2024/x/hello
```
